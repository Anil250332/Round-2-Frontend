# CodeRush Hackathon — Round 2 Frontend (Event Auction System)

Frontend client for the timed single-item auction system built with React, Vite, Tailwind CSS, and Socket.IO. Features a modern Black & White monochrome aesthetic with real-time bidding synchronization.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```
Runs at: `http://localhost:5173`

Ensure the backend server is running at `http://localhost:5000`.
